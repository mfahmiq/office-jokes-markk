# One-Line Office Jokes

A single line that makes office life funny — an entry for the [One-Line Office Jokes](https://make.fun/c/u-markk-st-one-line-office-jokes-a51f2bcc) competition on make.fun.

## The entry

> The office printer only jams when my deadline is five minutes away — it can smell fear.

## How to run

```sh
python3 main.py
```

This writes the entry to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`).
